About the Project

FIFA 2026 Insider is a Telegram WebApp built for the TxODDS Consumer and Fan Experiences hackathon track. The project transforms live FIFA World Cup data into an interactive football experience for fans.

Project Goal

The goal of the application is to make World Cup data more accessible, engaging and enjoyable by combining real-time information, football statistics and AI-powered insights inside Telegram.

Features

  • Live FIFA World Cup match data.
  • Fixtures and schedules.
  • Match events and statistics.
  • AI football insights.
  • Telegram WebApp integration.
  • Mobile-first user experience.
  • Fast and lightweight interface.
This project was created specifically for the TxODDS World Cup Hackathon.

Hackathon Information

  • Total prize pool: 16,000 USDT.
  • 1st place: 10,000 USDT.
  • 2nd place: 4,000 USDT.
  • 3rd place: 2,000 USDT.
  • Supported categories: Frontend, Backend, Blockchain, Mobile and Design.
