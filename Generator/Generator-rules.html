Bitcoin / Ethereum / Solana / TON

🇬🇧 English

The mnemonic is usually the same BIP39 seed phrase, but each network uses its own derivation path, key format, and address format.

One mnemonic, many wallets

A BIP39 phrase is only the seed source. The chain-specific wallet decides how to derive keys from it.

Path matters

Bitcoin, Ethereum, Solana, and TON can share a mnemonic but produce different accounts because the path changes.

Format matters

Bitcoin uses Base58Check / Bech32 / Bech32m, Ethereum uses 0x addresses, Solana uses base58 public keys, TON uses its own account format.

Одна фраза — багато гаманців

BIP39-фраза лише задає seed. Далі кожна мережа/гаманець обирає свою схему деривації.

Path має значення

Bitcoin, Ethereum, Solana і TON можуть мати один seed, але різні акаунти через різні шляхи.

Формат має значення

Bitcoin використовує Base58Check / Bech32 / Bech32m, Ethereum — 0x-адреси, Solana — base58 public keys, TON — власний формат account address.
